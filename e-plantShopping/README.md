# e-plantShopping — Paradise Nursery

A React plant-shopping application for the Paradise Nursery project.

## Features
- Landing page with the heading “Welcome to Paradise Nursery”
- Get Started button opens the plant listing
- About Us company information
- Three plant categories with six unique plants per category
- Plant thumbnails, names, prices, and Add to Cart controls
- Add to Cart disables after a plant is added
- Shared-style navigation for Home, Plants, and Cart
- Dynamic cart item count
- Cart item quantity increment/decrement and delete controls
- Item subtotals and overall total
- Checkout button displays a Coming Soon alert

## Tech stack
React, Vite, Redux Toolkit, React Redux, and CSS.

## Run locally
1. Install Node.js.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the localhost address printed by Vite.

Review the assessment rubric and test the app before submitting. The project uses remote Unsplash image URLs for plant thumbnails, so an internet connection is needed to load those photos.
